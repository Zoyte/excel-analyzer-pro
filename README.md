# Excel Analyzer Pro (Price Forecaster)

![Python](https://img.shields.io/badge/python-3.10+-blue.svg)
![Flask](https://img.shields.io/badge/flask-backend-lightgrey.svg)

**Excel Analyzer Pro** — это мощный веб-инструмент для глубокого анализа табличных данных (Excel/CSV) и прогнозирования временных рядов (цен, продаж, метрик). Проект сочетает в себе красивый и современный пользовательский интерфейс с продвинутыми алгоритмами машинного обучения под капотом.

## ✨ Ключевые возможности

* 📁 **Мгновенная загрузка данных:** Поддержка форматов `.xlsx`, `.xls`, `.csv`. Сводная статистика (KPI) по загруженному файлу генерируется автоматически.
* 🔍 **Продвинутая фильтрация:**
  * **Умные фильтры дат:** Специализированный фильтр по месяцам (например, анализ только 1-го квартала). Автоматическое распознавание любых текстовых форматов дат.
  * **Быстрые фильтры:** Поиск растущих/падающих трендов, фильтрация значений выше/ниже среднего.
  * **Кастомные условия:** Сборка сложных фильтров (больше, меньше, содержит, между, ТОП-N).
* 🔮 **Машинное обучение и Прогнозирование:**
  * Ансамбль моделей прогнозирования временных рядов: **Holt-Winters (ETS)**, **ARIMA (Auto-tune)**, **Polynomial Ridge Regression**.
  * Автоматический выбор лучшей модели на основе кросс-валидации (по метрике **MAPE** — средней абсолютной ошибке в процентах).
  * Расчёт доверительных интервалов (Confidence Intervals) для оценки рисков.
  * Защита от недостатка данных: встроенная резервная модель (Naive Trend) на случай слишком коротких рядов.
* 📊 **Интерактивная визуализация:** Построение графиков прогноза и исторических данных с помощью `Chart.js`.
* 🌓 **Современный UI/UX:** Адаптивный дизайн в стиле Glassmorphism (тёмная тема), плавные анимации и всплывающие уведомления.

## 🛠 Стек технологий

**Frontend:**
* HTML5 / Vanilla CSS3 (Custom Design System, Glassmorphism)
* Vanilla JavaScript (ES6+)
* [Chart.js](https://www.chartjs.org/) — для отрисовки интерактивных графиков.

**Backend:**
* [Python](https://www.python.org/)
* [Flask](https://flask.palletsprojects.com/) — легковесный веб-сервер.
* [Pandas](https://pandas.pydata.org/) & [NumPy](https://numpy.org/) — обработка и агрегация табличных данных.
* [Statsmodels](https://www.statsmodels.org/) — модели ARIMA и экспоненциального сглаживания (Holt-Winters).
* [Scikit-learn](https://scikit-learn.org/) — полиномиальная регрессия и пайплайны.

## 🚀 Как запустить проект локально

1. **Склонируйте репозиторий:**
   ```bash
   git clone https://github.com/your-username/excel-analyzer-pro.git
   cd excel-analyzer-pro
   ```

2. **Установите зависимости:**
   Убедитесь, что у вас установлен Python (желательно 3.10+). Рекомендуется использовать виртуальное окружение:
   ```bash
   pip install -r requirements.txt
   ```
   *(Если файла requirements.txt нет, установите пакеты вручную: `pip install flask pandas numpy scikit-learn statsmodels openpyxl`)*

3. **Запустите сервер:**
   ```bash
   python app.py
   ```

4. **Откройте в браузере:**
   Перейдите по адресу [http://127.0.0.1:5000](http://127.0.0.1:5000)

## 💡 Использование

1. Нажмите "Выбрать файл" или перетащите `.xlsx` / `.csv` файл в зону загрузки.
2. Воспользуйтесь левой панелью для фильтрации (например, выберите колонку с датой и оставьте только нужные месяцы). Нажмите **"Применить"**.
3. Перейдите во вкладку **"📊 Прогноз"**.
4. Укажите колонки с датой, ценой и выберите периодичность (например, Ежемесячно).
5. Нажмите **"🔮 Прогноз на 3 мес"**. Система подберёт лучшую ML-модель и выдаст результат с графиком и таблицей.
